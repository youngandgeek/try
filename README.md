🧩 Selenium Cucumber Java BDD Setup Project
This project is a Behavior-Driven Development (BDD) test automation framework built using Selenium WebDriver, Cucumber, and Java.
It demonstrates the setup of a basic Cucumber BDD project in IntelliJ IDEA with HTML report generation and reusable step definitions.

⚙️ Tech Stack
Component	Description
Java 11	Programming language used
Maven	Build and dependency management
Selenium WebDriver	Web browser automation
Cucumber	BDD framework for writing test scenarios in Gherkin
JUnit	Test runner for executing feature files
IntelliJ IDEA	IDE used for development
Cucumber HTML Reports	Generates interactive reports after test execution

🧠 Key Features
✅ Cucumber BDD with Gherkin syntax
✅ Reusable Step Definitions (e.g., login steps)
✅ Feature Files to describe scenarios in plain English
✅ Test Runner configured with reporting plugins
✅ HTML,JSON report generation after test execution
✅ Ready-to-use Selenium setup for browser interaction
